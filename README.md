# Book Reader (with Translation) 📚

An Android PDF reader designed to help readers understand English vocabulary through Roman Urdu meanings.

## 📥 Download the APK

**[⬇️ Download Book Reader for Android](https://github.com/zorvyn-exe/Book-Reader-with-Translation-/raw/refs/heads/main/Book%20Reader%20%28with%20Translation%29.apk)**

- File: `Book Reader (with Translation).apk`
- Version: 1.0.0
- Minimum Android version: Android 7.0 (API 24)

## ✨ Features

- Import PDF books from your device.
- Tap English words to look up Roman Urdu meanings.
- Use the built-in offline dictionary.
- Save vocabulary words for later review.
- Bookmark pages and track reading progress.
- Listen to English word pronunciations.
- Switch between light, dark, and sepia reading themes.

Some features may depend on the PDF's text layer and your device configuration.

## 📱 Installation

1. Download the APK using the link above.
2. Open the downloaded APK on your Android phone.
3. If Android asks, allow your browser or file manager to install unknown apps.
4. Tap **Install**.
5. Open **Book Reader (with Translation)**.

Only install APKs you trust.

## 🛠️ Build from Source

### Requirements

- JDK 17 or newer.
- Android SDK.
- Internet connection for downloading build dependencies.

### Build the debug APK

On Linux:

```bash
./gradlew assembleDebug
```

APK output:

```text
app/build/outputs/apk/debug/app-debug.apk
```

## 🧰 Technology

- Kotlin
- Jetpack Compose
- Android WebView and PDF.js
- Room database
- Android Text-to-Speech
